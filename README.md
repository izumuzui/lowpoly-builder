# Low Poly Builder

顔写真からPS1（初代PlayStation）風のローポリゴン3Dキャラクターを作り、Blenderで使える `.glb` として書き出すブラウザアプリ。

処理はすべて端末内で完結します。写真を含め、データが外部に送信されることはありません。

詳細な設計は [SPEC.md](./SPEC.md) を参照してください。

## 特徴

- **固定のローポリ・ベースメッシュ × 写真の顔テクスチャ** — メッシュをAIに生成させないため、ポリゴン数・UV・リグがすべて制御下にある
- **Mixamo標準のリグを内蔵** — 書き出した `.glb` にMixamoのアニメーションをリターゲットなしで適用できる
- **ビルドツール不要** — importmapとESモジュールのみ。`git push` だけでGitHub Pagesに反映される

## ローカルで動かす

ESモジュールを使うため、ファイルを直接開くのではなくHTTPで配信してください。

```bash
python3 serve.py
```

`http://localhost:4173` を開きます。

`python3 -m http.server` でも動きますが、キャッシュ制御ヘッダを送らないためブラウザが古いモジュールを使い回すことがあります。`serve.py` はキャッシュを無効化するだけの薄いラッパーです。

## 構成

```
index.html      importmap定義とマークアップ
serve.py        開発用サーバー（キャッシュ無効）
src/
  main.js       起動、画面の組み立て、状態管理
  skeleton.js   Mixamo標準スケルトンの生成
  body.js       体型スペック → SkinnedMesh
  atlas.js      UVアトラスの定義とベーステクスチャ描画
  face.js       写真 → 顔検出 → 位置合わせ → アトラス転写
  cropper.js    写真から貼る範囲を選ぶ画面（矩形 / フリーハンド）
  poses.js      ポーズ定義とボーンへの適用
  psx.js        PS1風マテリアル
  viewer.js     three.jsのシーン・カメラ・操作
  exporter.js   .glb / .png 書き出し
  config.js     モジュール以外の外部URL
bodies/         体型スペック
vendor/three/   取り込んだthree.js（update.shで更新）
samples/        書き出し例（Blenderでの確認用）
```

## 外部への通信

写真を含め、データが外部に送信されることは一切ありません。

three.jsは `vendor/` に取り込んであるため、**写真を使わない限り外部への通信は発生しません**。顔検出を使うときだけMediaPipe（本体・WASM・モデル）をCDNから取得します。WASMが11.5MBあるためリポジトリには入れず、初回利用時に動的に読み込む形にしています。

## 体型を追加する

1. `bodies/` に既存のJSON（`standard.json` が読みやすい）をコピーして新しいIDで保存する
2. 値を書き換える
3. `bodies/index.json` の `bodies` 配列に `{ "id": "...", "name": "..." }` を追加する

コードの変更は不要です。

### スペックの単位

`size` / `offset` / `proportions` は**すべて「身長を1としたときの比率」**です。メートルではありません。実寸なのは `height` だけです。この方式により、身長を変えても各パーツの関係が崩れません。

### よく使うフィールド

| フィールド | 意味 |
|---|---|
| `bone` | 追従させるボーン。接頭辞なしの短縮名（`Head`, `LeftArm`） |
| `size` | 幅・高さ・奥行き |
| `offset` | ボーン原点からのパーツ中心のずれ |
| `taperAxis` / `taper` | テーパー。`taper` は `[負側の端の倍率, 正側の端の倍率]` |
| `uvSet` | `head` / `torso` / `skin` / `cloth` |
| `mirror` | `true` でRight側を自動生成。`Left` 系ボーンにのみ指定可 |
| `detail` | このパーツが現れる最小の細かさ。省略すると常に表示 |
| `rotate` | パーツ中心まわりの回転（度、XYZ順） |
| `shape` | `box`（かかと・親指・指）または `rings`（頭・胴・腕・脚・手・足） |
| `axis` | `rings` の積み上げ軸。既定は `y`、腕は `x` |
| `sides` | `rings` の断面の角数。既定は8、手足は6 |
| `profile` | `rings` の輪郭 |

### 輪郭を変える

頭・胴・腕・脚は `shape: "rings"` で、断面を積み重ねた多角柱として作ります。

```json
"profile": [
  [0.00, 0.58, 0.66],
  [0.56, 1.00, 1.00],
  [1.00, 0.62, 0.66]
]
```

各行は `[位置, 倍率A, 倍率B]` で、積み上げ軸の負側から正側へ並べます。倍率は `size` に対する比です。頭を丸顔にしたければ下側の倍率を上げ、面長にしたければ下げます。

倍率が効く軸は積み上げ軸で変わります。

| axis | 倍率A | 倍率B |
|---|---|---|
| `y` | X（幅） | Z（奥行き） |
| `x` | Z（奥行き） | Y（高さ） |

腕のように `axis: "x"` のパーツを `mirror` すると、左右で向きが反転するため `profile` の並びは自動で逆にされます。手で書く必要はありません。

`proportions` でボーン位置そのものを動かせます（`chibi.json` が実例）。`mirror` と同様、`Left` 系だけ書けば `Right` 系は自動で補われます。

## Blenderへ持ち込む

1. アプリで `.glb を書き出す`
2. Blenderで `ファイル → インポート → glTF 2.0 (.glb/.gltf)`

テクスチャは `.glb` に埋め込まれているため、追加のファイルは不要です。

### Mixamoのアニメーションを適用する

ボーン名がMixamo標準（`mixamorig:Hips` 等）で出力されているため、[Mixamo](https://www.mixamo.com/) からダウンロードしたアニメーションのボーン名がそのまま一致します。

初期姿勢はTポーズ（Mixamoの標準）です。

## 画像を貼る

**顔・服・服（背面）・髪・ズボン・靴**の6枠があります。どれも同じ操作です。

- 枠をタップしてファイルを選ぶ
- 枠に画像をドラッグ&ドロップ
- ステージに落とすと顔として扱う
- 右上の × で外す

枠のサムネイルには**実際に貼られているテクスチャがそのまま映る**ので、結果を見ながら差し替えられます。

### 写真から範囲を選ぶ

読み込んだ写真から**使いたい範囲だけを囲って**貼れます。枠によって選べる方法が変わります。

**顔**

| 選び方 | 貼り方 |
|---|---|
| 自動 | 顔を検出し、**目の位置に合わせて**貼る。検出できた場合の既定 |
| 矩形 | 囲った範囲をそのまま顔に貼る。位置合わせはしない |

自動モードでは検出した目の位置に印が出ます。顔が検出できない写真（イラスト、横顔など）では自動が選べなくなり、矩形だけになります。

**服・ズボン・靴**

| 選び方 | 意味 | 貼り方 |
|---|---|---|
| 矩形 | この範囲を生地として使う | 縦横比を保って領域を埋める。服なら前・後・横・袖すべて |
| フリーハンド | この形を貼る | 囲った形の外は透明。下地の色が透ける。服なら**前面だけ** |

柄物の生地は矩形、ロゴやワッペンはフリーハンドが向いています。フリーハンドを前面だけにしているのは、ロゴが袖や背中にも出てしまうのを避けるためです。

画像がある枠をもう一度押すと、**同じ写真のまま範囲を選び直せます**。顔は自動と矩形を行き来できます。別の写真にしたいときは選択画面の「別の画像」から。

胴は胸・腹・骨盤の3パーツ、脚は腿・膝下の2パーツに分かれていますが、`uvGroup` によってUVがパーツをまたいで連続するため、**画像が繰り返されずに1枚として貼られます**。

### 実写を貼る場合

自分の写真から起こす場合は、**正面と背面の2枚**を用意してください。

| 枠 | 使う写真 |
|---|---|
| 顔 / 服 / ズボン / 靴 | 正面 |
| 服（背面） / 髪・後頭部 | 背面 |

服（背面）と髪は服より後に塗られるので、まず正面だけ貼って、あとから背面を足せます。

**テクスチャ解像度を512px以上に上げてください。** 既定の256pxでは胴が64×96pxしかなく、実写の柄が潰れて読めません（「見た目」→「テクスチャ解像度」）。

腕は写真の左右の端から取ります。胴を囲うときは**腕まで含めて**囲うと自然になります。中央だけを囲うと、胸元の柄（ネクタイなど）が肩に出ます。

## 服の種類

上半身と下半身をそれぞれ選べます。UV領域だけでなく**形も少し変わります**。

| 服（上） | 変化 |
|---|---|
| タンクトップ | 肩から先が肌。胴がわずかに細い |
| Tシャツ | 半袖（既定） |
| 長袖シャツ | 手首まで袖 |
| パーカー | 長袖。胴と袖が太くゆったり |
| ジャケット | 長袖。肩が張り、着丈が少し長い |

| 服（下） | 変化 |
|---|---|
| 長ズボン | 既定 |
| 半ズボン | 膝下が肌。腿がわずかに太い |
| スカート | 腰から裾が広がり、脚は肌 |

袖丈は独立した設定にしていません。タンクトップの袖丈は意味を持たないためです。

定義は `src/clothing.js` にあり、追加も同ファイルに書き足すだけです。形は**倍率**（`scale`）と**ずらし**（`offsetDelta`）で指定します。`size` は身長比で体型ごとに違うため、絶対値で書くと体型の数だけ用意する羽目になります。

## ポーズ

15種類（Tポーズ / 立ち / 歩き / 座り / 手を振る / 走り / ジャンプ / しゃがみ / 腕組み / 考える / 指差す / 万歳 / 敬礼 / 腰に手 / お辞儀）。

`src/poses.js` にボーンの回転（度）で定義してあり、追加も同ファイルへ書き足すだけです。左右対称のポーズは `Left` 系だけ書けば `Right` 系が自動生成されます。

ポーズは `.glb` にもボーンの姿勢として書き出されます。**Mixamoのアニメーションを当てるならTポーズのまま書き出してください。**

## モバイル

iPhoneを含むモバイルに対応しています。900px以下では上下2段（3Dプレビューが上、操作パネルが下）になり、セーフエリア・タップ領域・横スクロール防止を処理しています。

## 見た目の設定

| 項目 | 内容 |
|---|---|
| 頂点ジッター | 頂点を320×240相当のグリッドにスナップする。動かすと座標が量子化されプルプル揺れる |
| テクスチャの歪み | 透視補正を打ち消す（アフィンテクスチャマッピング）。面が傾くとテクスチャがぐにゃりと歪む |
| ライティングなし | 既定でオン。陰影は頂点カラーに焼き込んであるため実行時のライトは不要（オンにすると二重に暗くなる）。`.glb` には `KHR_materials_unlit` として書き出される |
| メッシュの細かさ | 断面の角数とリング数の倍率。輪郭は変えないのでシルエットは保たれる |
| 描画解像度 | 低解像度で描いて引き伸ばす。PNG書き出しも同じ粗さで出力される |

### 細かさとポリゴン数（標準体型）

細かさを上げると分割が細かくなるだけでなく、**パーツそのものが増えます**。

| 段階 | 追加されるパーツ | ポリゴン数 |
|---|---|---|
| 粗い | — | 652 |
| 標準 | 肩 | 976 |
| 細かい | ＋耳・親指・かかと | 1,340 |
| とても細かい | ＋指3本 | 2,944 |

PS1期の実機水準は300〜800ポリゴン程度です。「細かい」以上は当時のハードでは動かない密度なので、PS1らしさを取るか滑らかさを取るかで選んでください。

ディテールを足すには、JSONのパーツに `"detail": "high"` のように書き加えるだけです。

### オフセットの基準に注意

`offset` は**ボーンの位置からの相対**です。頭パーツ自体が `offset` で持ち上げてある場合、耳のように「頭に付けたい」パーツは頭パーツの `offset` を足した値を書く必要があります。ボーン基準のまま書くと、頭パーツの持ち上げ分だけ下にずれます。
